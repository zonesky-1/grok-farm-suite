=============================================================================
         PANDUAN LENGKAP MEMBUAT CLOUDFLARE EMAIL WORKER UNTUK GROK
=============================================================================

Agar tool '0_AUTO_CREATE_AND_CONNECT_9ROUTER.bat' bisa membuat akun Grok 
dan menangkap OTP secara otomatis, Anda memerlukan 1 Worker Cloudflare 
yang terhubung dengan fitur Email Routing domain Anda.

-----------------------------------------------------------------------------
LANGKAH 1: MEMBUAT WORKER DI CLOUDFLARE
-----------------------------------------------------------------------------
1. Buka dashboard Cloudflare: https://dash.cloudflare.com/
2. Di menu samping kiri, klik "Compute (Workers & Pages)" -> "Workers & Pages".
3. Klik tombol biru "Create application" -> pilih "Create Worker".
4. Beri nama worker Anda (misal: "grok-mail-worker"), lalu klik "Deploy".
5. Setelah terdeploy, klik "Edit code".
6. Hapus semua baris kode bawaan di editor tersebut.
7. Buka file 'cloudflare_worker.js' yang ada di folder tools ini, COPY SELURUH 
   KODENYA dan PASTE ke editor Cloudflare Worker tersebut.
8. Di baris paling atas (const MY_DOMAIN = "domainanda.com";), ganti 
   "domainanda.com" dengan nama domain Anda sendiri (misal: "tokoku.id").
9. Klik tombol "Deploy" / "Save and deploy" di pojok kanan atas.
10. Salin URL Worker Anda yang berakhiran '.workers.dev'
    (Contoh: https://grok-mail-worker.subdomain.workers.dev).


-----------------------------------------------------------------------------
LANGKAH 2: MENGHUBUNGKAN EMAIL ROUTING DOMAIN KE WORKER
-----------------------------------------------------------------------------
1. Di dashboard Cloudflare, buka domain Anda (misal: tokoku.id).
2. Di menu samping kiri, klik "Email Routing".
   (Jika belum aktif, ikuti petunjuk Cloudflare untuk menambahkan DNS MX 1x klik).
3. Masuk ke tab "Routing rules".
4. Pada bagian "Catch-all address" (atau Default rule):
   - Klik "Edit"
   - Action: Pilih "Send to a Worker"
   - Destination Worker: Pilih nama Worker yang Anda buat di Langkah 1 
     (misal: "grok-mail-worker").
   - Klik "Save".


-----------------------------------------------------------------------------
LANGKAH 3: MENGISI FILE 'config.json' DI TOOLS INI
-----------------------------------------------------------------------------
1. Buka file 'config.json' yang ada di folder tools ini dengan Notepad.
2. Isi seperti berikut:

{
  "email_worker_url": "https://grok-mail-worker.subdomain.workers.dev",
  "email_domain": "tokoku.id",
  "default_headless": true
}

3. Simpan file 'config.json'.


-----------------------------------------------------------------------------
LANGKAH 4: SELESAI! TINGGAL JALANKAN TOOLS
-----------------------------------------------------------------------------
Double-click file '0_AUTO_CREATE_AND_CONNECT_9ROUTER.bat'. 
Tools akan otomatis membuat akun Grok dalam jumlah banyak, menangkap OTP 
lewat Worker Anda dalam hitungan detik, dan menginjeksi token aktif ke 9Router!
